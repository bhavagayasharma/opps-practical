# Java 5th Semester Practicals (1-10)

Each practical has its own folder (`pra_1` through `pra_10`) and contains:
- `Main.java` — complete Java program
- `README.md` — compile and run instructions

All programs are written without code comments. Each program uses `Main` as its public class, so compile and run one practical at a time from its folder.

Requirements: JDK installed and `javac` / `java` available in the terminal.

Example:
```bash
cd pra_1
javac Main.java
java Main
```
